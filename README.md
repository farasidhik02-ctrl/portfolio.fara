# Fara Sidhik Portfolio

A static all-rounder professional portfolio built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
Upload the contents of this folder to a GitHub repository, then enable Pages under Repository Settings > Pages.

## Notes
- No downloadable CV is included. Tailored CVs can be sent separately with each application.
- All supplied portfolio thumbnails and personal images are already embedded under `assets/`.
- External work samples open in a new tab.
