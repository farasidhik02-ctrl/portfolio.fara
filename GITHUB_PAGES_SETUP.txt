GITHUB PAGES SETUP

Upload the CONTENTS of this folder to the ROOT of the repository.
The repository root should visibly contain:
  index.html
  styles.css
  script.js
  .nojekyll
  assets/   <-- folder, not loose image files in root

Inside assets/ should be profile.jpg and all news/video/beyond images.

Then on GitHub:
1. Repository > Settings > Pages.
2. Under Build and deployment, choose Source: Deploy from a branch.
3. Branch: main
4. Folder: / (root)
5. Click Save.
6. Wait 1-3 minutes and refresh the Pages URL.

Do NOT upload the enclosing fara_github_pages_ready folder as a subfolder.
Do NOT move images out of assets/ because index.html uses ./assets/filename paths.
